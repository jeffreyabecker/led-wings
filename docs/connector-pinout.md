# Connector Pinout — Wiring Legend (4-Pin Module Chains)

> The shared interface for the standard strip modules: a 4-pin JST-GH on **each end** carrying
> power + data, chained tip-to-tail; power injected via harness pigtails. The pin maps and
> colors below are the canonical build legend.

## Topology

- **Data daisy-chains** module-to-module: each module's `SDO`/`CKO` (OUT end) feeds the next
  module's `SDI`/`CLK` (IN end) through a 4-wire jumper. The last module's OUT is unused
  (end of chain).
- **Power rides the chain** through the same 4-pin connectors; **injection pigtails** tap
  `+5V`/`GND` every 4–6 modules from the power-hubs (fused per feed).
- **Controller** feeds the first module of each chain: level-shifted `SDI`/`CLK` into the IN
  connector, power from a hub feed.

## Signals

| Signal | Meaning |
|--------|---------|
| GND | Power ground (also the data signal return path) |
| +5V (V+) | LED power (rides the chain; injected from power-hubs) |
| SDI | Serial data in (from controller, or previous module's `SDO`) |
| CLK | Serial clock in (from controller, or previous module's `CKO`) |
| SDO | Serial data out (regenerated by last LED, to next module) |
| CKO | Serial clock out (regenerated by last LED, to next module) |

## Wire colors

| Signal | Wire color |
|--------|------------|
| +5V (V+) | Red |
| GND | Black |
| SDI | Yellow |
| CLK | Green |
| SDO | Orange |
| CKO | Blue |

## Connector pin maps (canonical)

**IN — 4-pin (controller / previous module → this module)**

| Pin | Signal |
|-----|--------|
| 1 | GND |
| 2 | SDI |
| 3 | CLK |
| 4 | +5V (V+) |

**OUT — 4-pin (this module → next module)**

| Pin | Signal |
|-----|--------|
| 1 | +5V (V+) |
| 2 | CKO |
| 3 | SDO |
| 4 | GND |

## Wiring rules

- **Module jumpers:** 4-wire, **crossed pin order** — OUT pin 1→IN pin 4, 2→3, 3→2, 4→1 —
  so `GND`/`+5V` land on the outer pins at both ends and `SDO`→`SDI` / `CKO`→`CLK` pair in
  the middle. The roles cross at the connectors, not in the wire.
- **Controller → first module:** 5 V-logic `SDI`/`CLK` (Pixelblaze + 74AHCT125 level shifter)
  into IN pins 2/3; power into IN pins 4 (`+5V`) and 1 (`GND`) from a hub feed. Add a series
  R (33–100 Ω) at the chain head if the bench shows ringing.
- **Injection:** red `+5V` / black `GND` pigtails from the hub tap into the chain every 4–6
  modules — solder to a jumper splice or module pad and strain-relieve every tap. Fuse each
  injection feed at the hub.
- **Brightness:** cap ≤ 20–25 % — a 630-LED chain head carries ~5 A @ 20 %; the 1 A/circuit
  JST-GH connectors are sized for inter-injection current only (≤ ~0.8 A).
- **Wire gauge:** power + jumpers 24–20 AWG silicone; data 26–28 AWG.

## Rationale

- Power + data share one 4-pin so each module is a dumb plug-and-play link: two connectors,
  no pigtails on the module itself.
- Injection cadence (4–6 modules) keeps connector current inside rating without a connector
  per module — the hub fan-out stays coarse-grained.
- A daisy chain needs no `SDO`/`CKO` return to a hub — the last module's OUT is simply unused.
- The clocked SK9822 protocol tolerates hop-to-hop runs better than single-wire NRZ, and each
  LED re-buffers the signals, so short module hops are a non-issue.
