# Connector Pinout — Logical Contract

> The shared signal/pin interface for all boards in this project (SK9822 addressable LED
> chain, home-run to a central hub). Physical parts — part numbers, header colors,
> orientation — live in each board's own docs.

## Topology

- Every LED board has **one 6-pin port** and home-runs a single cable back to the central
  hub (no board-to-board chaining on the wing).
- The hub owns the serial chain: it routes port N's `DO`/`CO` into port N+1's `DI`/`CI`
  in copper, and drives one `DATA` + one `CLK` into port 1.
- Power is delivered per-board on the same 6-pin cable — no separate power-injection ports.

## Signals

| Signal | Meaning |
|--------|---------|
| GND | Power ground + signal return |
| +5V (VCC) | LED power (one board per cable) |
| DI | Serial data in (from hub, or previous port's `DO`) |
| CI | Serial clock in (from hub, or previous port's `CO`) |
| DO | Serial data out (regenerated by last LED, back to hub) |
| CO | Serial clock out (regenerated by last LED, back to hub) |

`DI`/`CI` and `DO`/`CO` are separate wires because data streams through the board in real
time — the two directions cannot share a wire.

## Wire colors

| Signal | Wire color |
|--------|------------|
| +5V (VCC) | Red |
| GND | Black |
| DI | Yellow |
| CI | Green |
| DO | Orange |
| CO | Blue |

## Pin map (canonical) — 6-pin home-run port

| Pin | Signal |
|-----|--------|
| 1 | GND |
| 2 | DI |
| 3 | CI |
| 4 | DO |
| 5 | CO |
| 6 | +5V (VCC) |

- Power on the outer pins (1/6), signals inner (2–5). A reversed cable gives reverse
  polarity (caught by protection) and a signal swap that is moot while the board is
  unpowered.
- Same pin map on both ends; roles are opposite: the hub **drives** `DI`/`CI` and
  **receives** `DO`/`CO`, the board does the reverse. The cable is straight 1:1 — the
  roles cross, not the wires.

## Cabling rules

- **Hub ↔ board** is straight 1:1 (pin 1↔1 … pin 6↔6) — off-the-shelf 6-pin cable.
- **Hub-internal chain:** port N's `DO`/`CO` → port N+1's `DI`/`CI`, routed in copper.
  The final port's `DO`/`CO` are unused (end of chain).
- **Wire gauge:** JST-PH contacts accept 30–24 AWG; each home-run carries only its own
  board's current, so per-port current is well under the 2 A limit.
- **2 A limit** per 6-pin circuit — one board per port, so no per-cable concern.

## Rationale

- Home-run keeps each board to a single connector and moves routing, power distribution,
  and fusing to the hub — worth it because the board family is built ~140× while the hub
  is built once.
- Power on the outer pins keeps reverse-polarity safety; the hub fuses every port.
- `DO`/`CO` returning to the hub is what lets the hub chain in copper and add per-hop
  bypass jumpers for field repair.
- One connector + one cable type replaces the old 4-pin IN + 4-pin OUT + 2-pin PWR scheme.
