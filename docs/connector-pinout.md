# Connector Pinout — Logical Contract

> The shared signal/pin interface for all feather boards in this project (SK9822 addressable
> LED chain). Physical parts — part numbers, header colors, orientation — live in each board's
> own docs.

## Topology

- **Data daisy-chains** feather-to-feather: the controller drives one `DI`/`CI` pair into the
  first feather; each feather's `DO`/`CO` feeds the next feather's `DI`/`CI`. The last
  feather's `DATA OUT` is unused (end of chain).
- **Power fans out** from local power-hubs: each feather gets `+5V`/`GND` over a short 2-wire
  run from a nearby power-hub.
- Power and data use **separate connectors and cables**.

## Signals

| Signal | Meaning |
|--------|---------|
| GND | Power ground + signal return |
| +5V (VCC) | LED power (from power-hub) |
| DI | Serial data in (from controller, or previous feather's `DO`) |
| CI | Serial clock in (from controller, or previous feather's `CO`) |
| DO | Serial data out (regenerated by last LED, to next feather) |
| CO | Serial clock out (regenerated by last LED, to next feather) |

## Wire colors

| Signal | Wire color |
|--------|------------|
| +5V (VCC) | Red |
| GND | Black |
| DI | Yellow |
| CI | Green |
| DO | Orange |
| CO | Blue |

## Pin maps (canonical)

**Power — 2-pin (feather ↔ power-hub)**

| Pin | Signal |
|-----|--------|
| 1 | GND |
| 2 | +5V (VCC) |

**Data IN — 3-pin (controller / previous feather → this feather)**

| Pin | Signal |
|-----|--------|
| 1 | GND |
| 2 | DI |
| 3 | CI |

**Data OUT — 3-pin (this feather → next feather)**

| Pin | Signal |
|-----|--------|
| 1 | GND |
| 2 | DO |
| 3 | CO |

## Cabling rules

- **Inter-feather data:** feather N's `DATA OUT` → feather N+1's `DATA IN`, straight 1:1
  (pin 1↔1, 2↔2, 3↔3). Pin 2 carries `DO` at the source and `DI` at the sink; pin 3 is
  `CO`→`CI`. The roles cross at the connector, not in the wire.
- **Controller → first feather:** level-shifted (3.3 V → 5 V) `DI`/`CI` into the first
  feather's `DATA IN`; series R + ESD/TVS at the controller.
- **Power:** 2-wire (red/black) from power-hub to each feather.
- **GND** appears on all three connectors — the data cable carries its own return so the
  high-speed signals have a local reference path.
- **Wire gauge:** JST-PH contacts accept 30–24 AWG; each power run carries only its own
  feather's current, so per-run current is far below the 2 A limit.

## Rationale

- Power and data are split so power can scale independently (add a power-hub where a cluster
  needs it) while the data chain stays thin and short.
- A daisy chain needs no `DO`/`CO` return to a hub — the last feather's `DATA OUT` is simply
  unused.
- One data wire + one clock wire per hop keeps cables minimal; the clocked SK9822 protocol
  tolerates hop-to-hop runs better than single-wire NRZ.
